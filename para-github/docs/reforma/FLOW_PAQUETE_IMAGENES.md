# Paquete de imágenes para Google Flow (ENGLISH47 2.0)

Con estas imágenes, Trellis las convierte en 3D y Blender las pule. Guárdalas en `D:\english 47 dou\art\flow\` con el nombre indicado. **Empieza por el bloque A:** es el que más cambia la app.

## Reglas para TODAS (lecciones de tu flujo de AtomicRupture)
- Objeto o personaje **solo**: fondo liso claro, **sin sombra, sin suelo, sin brillos ni partículas, sin texto**.
- Mismo estilo en todo: *stylized 3D cartoon, soft Pixar-like render, rounded shapes, warm studio lighting, high detail, clean silhouette*.
- Formato cuadrado (1:1), mínimo 1024 px. Formas de caja pura fallan en Trellis: redondea las esquinas.
- Si Flow deja fondo, no importa: lo recorto con `cortar_hoja.py`.
